# 最终渲染：守住结构，再补质感

最后一渲染步要分成两层：结构层决定毫米、角度和毫升，外观层只改纹理和光照。生成模型不能担任结构层。

## 结构层用网格渲染

咨询演示里，结构已经由前面的形变层算完。最后一步应把这份结果光栅化，而不是再交给模型重新理解一张脸。

二维路径把形变后的像素当作底图，法线由位移的雅可比算出来，再用延迟着色加高光和阴影。三维路径用 Three.js：顶点按标定后的毫米或角度移动，照片投影成反照率，`MeshPhysicalMaterial` 或一段自定义皮肤着色器负责粗糙度、高光和皱褶暗带。光照是着色器参数，移动光源不会移动顶点。Babylon.js 能做同样的事，材质编辑器更完整，但运行时更大。Unity HDRP 的皮肤效果更好，却不适合嵌进诊所网页，第一版不必上。

高斯溅射和延迟神经渲染（MeGA 这类，网格加神经纹理，头发再用高斯）在多视角视频上更像照片。它们把原图的几何和光照烘在一起。单张咨询照片没有可训练的身份纹理，咨询时也来不及为每个人优化。DeferredGS 能把光照和纹理拆开，仍然不知道 3.5 mm 是多少。这些适合以后有环绕视频、并且网格已经按参数改完之后，用来提高新视角的质感，不适合当第一版的结构渲染器。

## 扩散模型只做外观修补

ControlNet、IP-Adapter、InstantID、PuLID、IC-Light 都不接受毫米输入。深度图和法线图是相对的，2 mm 的鼻背变化常常小于深度估计本身的误差，去噪时会被拉回一张「更像人脸」的鼻子。

若要用它们提高皮肤质感，条件图必须来自已经形变的结果，而不是原片：

1. 用结构层渲染出深度、法线和编辑区掩膜。
2. 只在掩膜内做低强度修补。ComfyUI 里用 FLUX.1 Fill 或 SDXL Inpaint，去噪大约 0.15–0.35。
3. 深度 ControlNet 和法线 ControlNet 的条件图用形变后的渲染。SDXL 可用 `diffusers/controlnet-depth-sdxl-1.0-small`，权重约 0.4–0.8。边缘图要先画上新的双眼皮褶皱，否则 Canny 会把旧的单眼皮边缘锁回去。
4. 掩膜外的像素用原渲染覆盖回去，做到逐像素相同。
5. 再检测一次标志点。鼻背、唇前突、口角角度或褶皱位置超出公差，就丢掉这张图，退回结构层的结果。

身份模块和结构编辑是对着干的。InstantID、IP-Adapter、PuLID 的权重越高，脸越回到术前，鼻高和唇形会被抹平。身份权重只适合贴脸颊纹理块，不要盖住鼻、唇、眼睑和口角。IC-Light 适合在几何已经验收之后改灯光；它会改轮廓，小脸还容易塌，不能拿来执行 3.5 mm 的鼻背。

商用接口同样没有毫米参数。fal 的 FLUX Fill、BFL 的 FLUX.1 Fill 可以只重画掩膜内。PuLID Flux（`fal-ai/flux-pulid`）和 FLUX Redux 负责身份和风格。调用时仍然要做掩膜外回贴和事后测量。提示词里写「鼻背加 3.5 mm」不会被执行。

## 怎样保证数字被画出来

- 毫米、毫升和角度只进入形变层，变成顶点或控制点位移。渲染器消费的是这些坐标。
- 外观参数单独做：粗糙度、高光强度、皱褶暗度、光源方向。它们不写回几何。
- 双眼皮是在上睑缘上方按可见宽度画褶皱带，不把整只眼睛拉开。
- 丰唇只放大红唇、钉住口角和唇峰；前突固定约 1 mm，不随毫升继续加。
- 嘴角注射档和手术档用两套角度，渲染时只旋转口角附近的顶点。
- 输出前用同一套标定再量一次。未标定的照片不显示绝对毫米。

## 生成模型会在哪里改掉结构

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 鼻背加高后又变平 | 深度条件太弱，或身份权重把原鼻形拉回 | 提高形变后深度图的约束，编辑区关掉身份模块 |
| 新双眼皮没有出现 | Canny 锁的是原图边缘 | 先把新褶皱画进边缘图和法线图 |
| 嘴唇变厚但口角跟着动 | 整脸重绘，掩膜太大 | 掩膜收在红唇内，口角顶点钉死 |
| 口角角度被笑纹带跑 | 模型按训练分布把嘴画成微笑 | 口角只做几何旋转，扩散不覆盖口角 |
| 掩膜边界发虚、邻接皮肤变色 | 高去噪加上整图 VAE 往返 | 去噪不超过约 0.35，掩膜外回贴原像素 |
| 灯光一改，鼻型也变了 | IC-Light 一类重打光会改轮廓 | 灯光放在着色器里；用了重打光就必须再测标志点 |
| 侧脸和正脸对不上 | 两张图分别重绘 | 同一网格渲染正脸和侧脸，二维结果只作回退 |

第一版的最终画面用 Three.js 或二维延迟着色即可严格跟上结构，并用滑块控制皮肤和光照。扩散修补留到测量门槛之后，作为可选的质感层。
