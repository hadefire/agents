# 面部医美项目与常用数值（演示用）

数值来自整形外科文献、人体测量和假体产品目录的公开范围，人群以东亚面部整形文献为主。同一项目在不同研究里差几个毫米很常见。演示系统应把它们做成可调区间，并标注「模拟效果，非医疗建议」。

## 眼睛

- **埋线重睑（非切开双眼皮）**：用缝线把皮肤固定到睑板或提肌腱膜，形成褶皱。适合皮肤薄、脂肪少。固定点常见 3–6 点；部分术式在线上做 4–5 mm 小口。闭眼设计高度常见 **6–8 mm**（保守 **5.5–7 mm**，偏宽 **7–8 mm**），一般不超过 **9–10 mm**。睁眼可见褶皱亚洲人常希望不超过约 **4 mm**。持久性弱于切开，可随时间变浅。
- **切开重睑 / 部分切开**：切开法沿设计线全层切开，可去皮、眼轮匝肌和眶隔脂肪；部分切开中央切口约 **5–8 mm**。设计高度与埋线相同，**6–8 mm** 最常被引用。褶皱形态：开扇（内侧收窄）、平行、新月。亚洲睑板高度约 **6–8 mm**（一组测量上睑中央睑板宽约 **9.3 mm**）。
- **上睑下垂矫正**：把上睑缘抬高，增加角膜暴露。正常 MRD1（角膜反光点到上睑缘）约 **3–4 mm**。下垂量：轻度 **≤2 mm**，中度 **2–4 mm**，重度 **>4 mm**。提肌力正常约 **12–15 mm**，低于约 **8 mm** 时单做双眼皮往往不够。缝线法在薄睑上大约 1 环抬 **1 mm**、2 环抬 **2 mm**；厚或瘢痕睑效果可大约减半。
- **内眦开大（开内眼角 / 内眦赘皮矫正）**：暴露泪阜、加长睑裂、缩小内眦间距。一组 306 例：内眦间距 **38.4 → 35.9 mm**（约减 **2.5 mm**），睑裂长 **26.8 → 27.9 mm**（约加 **1.1 mm**，术后即刻约 **+2 mm**），内眦角 **57° → 44°**，眦倾斜 **8.5° → 7.1°**。皮肤重置设计里，新内眦到泪湖约 **4–6 mm**。自然效果常保留泪阜内侧约三分之一覆盖。
- **外眦开大 / 眼尾矫正**：水平加长并常略降低上斜的外眼角。加长平均约 **3 mm**（报告范围 **2–5.5 mm**），理想约 **3–4 mm**；外眦到眶缘间距宜大于 **4 mm**（韩国测量均值 **5.4 ± 1.5 mm**）。固定点在下睑缘 **3 mm** 以内。韩国成人睑裂长约男 **26.8 mm**、女 **26.1 mm**；外眼角上斜约男 **7.9°**、女 **8.8°**。中文临床科普常把内外眦连线与水平线夹角约 **10°** 视为协调，接近 **15°** 偏蒙古样上斜。
- **泪沟**：填充用玻尿酸，每侧每疗程常见 **0.2–0.5 mL**，不少指南单次不超过 **0.5 mL**；文献均值约 **0.56 mL/侧**（常含睑颊沟）。宜宁少勿多。手术用眶脂转位，向下剥离约 **10–12 mm** 盖过眶缘，没有固定毫升数。

演示滑块建议：褶皱高度 6/7/8 mm、褶皱型（开扇/平行）、MRD1 +1/+2 mm、内眦睑裂 +1～2 mm、外眦 +3 mm 与倾斜 −1～2°、泪沟容量 0.2/0.4 mL。

## 鼻子

- **隆鼻（鼻背增高）**：垫高低平鼻背。一组亚洲复合假体：长 **3.8–4.5 cm**（均值 **4.1 cm**），厚 **1.5–5.0 mm**（均值 **3.7 mm**）。增量经验：约 **2–3 mm** 可用软骨或筋膜，**3–5 mm** 常用假体或筋膜包裹软骨，**>5 mm** 更常考虑肋软骨。因皮肤厚，表面缺口常需再加 **1–2 mm**。韩国皮肤厚度约：鼻根 **3.3 mm**、鼻背 **2.4 mm**、鼻尖 **2.9 mm**、鼻小柱 **2.3 mm**。韩国年轻人群比例（鼻长:鼻尖突出:鼻背高:鼻根高）约 **2 : 0.97 : 0.61 : 0.28**，对照白种人约 **2 : 1 : 1 : 0.75**。
- **鼻背降低 / 驼峰**：东亚初级鼻整形更常是加高而不是降低。真有驼峰时做成分性少量切除，并保留背侧与尾侧各至少约 **10 mm** 的 L 形支架。
- **鼻尖成形（抬高、延长、缩窄）**：加强并前突鼻尖。Goode 指数（鼻尖突出/鼻长）正常约 **0.55–0.60**，大于 **0.60** 偏过突，小于 **0.55** 偏不足；白种人传统理想约 **0.67**，亚洲目标常靠近 **0.60**。女性鼻尖定义点约高出鼻背 **6–10 mm**。鼻唇角：女性约 **95–105°**（有文献写到 **110°**），男性约 **90–95°**。
- **鼻翼缩小**：最后做。民族鼻整形文献里，鼻翼超出内眦垂线 **>2 mm** 时，切除量常见 **6–12 mm**（两侧可不等）。这是偏宽鼻翼文献里的切除范围，东亚诊所通常更保守、按个体画线，不宜把 6–12 mm 当成默认演示值。演示可用鼻翼外展减少 **2–4 mm** 作为温和档。

演示滑块建议：鼻背 +2 / +3.5 / +5 mm，鼻尖 Goode 收到约 0.60，鼻唇角收到女性 95–100°，鼻翼外展 −2～4 mm。

## 唇与口周

- **玻尿酸丰唇**：每唇常见 **0.5–1.0 mL**，单次双唇合计多控制在 **1–1.5 mL**；薄唇可分次，间隔约 15–30 天。注射深度常不超过约 **2.5 mm**，每点 **0.05–0.1 mL**。1 mL 研究中 4 周体积增加约 **0.8–1.1 mL**，上唇前突约 **0.7–1.1 mm**；另一研究上唇前突约 **1.3 mm**、下唇约 **1.0–1.4 mm**。上:下唇视觉比例常参考约 **1 : 1.6**。
- **上唇提升（人中缩短，bullhorn）**：切除鼻底下皮肤。切除高度常见 **4–11 mm**，常规 **5–7 mm**，想增加露齿约 **7–9 mm**，超过 **11 mm** 不建议。尸体研究：切 **5 mm** 并剥离后，人中缩短可超过切除量（约 **7.6 mm**）。一组病例：上唇长度约减 **24%**，红唇露出约增 **33%**，露齿约 **+1.75 mm**。人中缩短主要抬唇中部；外侧口角下垂常要另做嘴角上扬，否则两侧会显得更下垂。
- **嘴角上扬（口角提升）**：把下垂口角抬向水平或略上翘。两种做法，升幅不一样。
  - 注射：肉毒打在降口角肌，减弱下拉。注射点常在口角外 **8–10 mm**、下 **8–15 mm**（也有写成外下各约 **1 cm**）。每点 **2–4 U**，每侧 **1–3** 点，每侧总量多不超过 **8 U**；综述剂量约每侧合计 **4–10 U**。约 2 周见效，1 个月较明显，维持约 **6–9 个月**。客观升幅小于手术：每侧 **3 U** 的一组里口角高度平均增加 **5.2%**，没有稳定的毫米数。另一组减弱降口角肌后，口角外展约 **+1.9 mm**、相对水平面约 **+1.9°**（这是面瘫相关测量，只能当注射档上限参考）。口角或木偶纹处再加玻尿酸 **0.1–0.2 mL**，主要填平凹陷；系统综述认为填充本身很少真正把口角抬起来。
  - 手术：口角上方切除一小块皮肤，常同时切断或切除降口角肌上 1/3，把口角缝到更高位置。51 例测量：术前左右口角角约 **−3.1° / −3.4°**，术后约 **+3.6° / +3.3°**，净变化约 **+6.5° 到 +7°**。外侧上翘切除支：长 **1 mm** 只轻微改角度，**2–5 mm** 逐级加大；拐点相对口角约 **90–120°**。再长容易变成不自然的「小丑笑」。设计点常比求美者想要的位置再高约 **30%**，沿红唇缘的切口长度约为抬高距离的 2 倍。东亚年轻求美者瘢痕增生相对多见，文献里明显瘢痕大约 **4%** 量级。
- **唇外翻（lip flip）**：肉毒打在上唇口轮匝肌浅层，让红唇略外翻，不增加容量。总量常见 **4–6 U**（每点 **0.5–1 U**，约 4 点），点位约在红唇缘上 **5 mm**、人中柱外侧约 **10 mm**。维持约 **6–12 周**，短于丰唇。
- **木偶纹填充**：玻尿酸填口角向下的沟，每侧常见 **0.5–1.0 mL**；只托口角时更小，约 **0.2–0.3 mL**。它让沟变浅，不等同于嘴角上扬。
- **人中柱填充**：每侧人中嵴 **0.05–0.1 mL**，只加强人中轮廓。
- **口周细纹**：肉毒总量约 **2–3 U**（沿红唇缘每点约 **0.5 U**），或填充每点约 **0.05 mL**。露龈笑也常做，每侧约 **2–6 U**，属于邻项，不改变唇体积。

演示滑块建议：双唇合计 0.8 / 1.2 mL，前突约 +1 mm；唇提升切除 5 / 7 mm；嘴角上扬分两档——注射约 **+2°** 或高度 **+5%**，手术约 **+3° / +7°**（外侧切除支 **1 / 3 / 5 mm**）。木偶纹用每侧 0.3 / 0.7 mL，不要把它画成口角上移。

## 下巴、颧骨、下颌

- **假体垫下巴**：前突是主参数。临床粗分：轻度后缩约 **4 mm**，中度 **6–8 mm**，明显后缩 **10–12 mm**。商品规格例：解剖型加长假体小号到加大约前突 **4.3–7.5 mm**；曲线型中央假体前突约 **4.5–7 mm**，宽约 **3.1–4.4 cm**，高约 **1.1–1.5 cm**。假体通常让下巴变宽；截骨前移较多时下巴会变窄。
- **截骨颏成形（滑动 genioplasty）**：可前移、后移、加长、缩短、缩窄。韩国诊所公开范围：前移 **2–10 mm**，后移 **2–8 mm**，缩短 **2–10 mm**，加长 **2–6 mm**，中央去骨缩窄 **2–10 mm**。文献中央骨条宽 **6–12 mm**，顶角 **50–65°**。前移 **8–10 mm** 时正面也会明显变窄。一处诊所把颏长 **3–3.5 cm** 称为常见参考。
- **颧骨内推（颧骨缩小）**：体部去骨条常见 **2–6 mm**（常用 **3–5 mm**），体部后移 **0–4 mm**，颧弓内移 **0–5 mm**。一组固定切 **6 mm** 的 CT：面宽（颧突间距）**102.1 → 95.0 mm**（约 **−7.1 mm**），内移 **3.3 mm**，后移 **3.2 mm**，弓后移 **3–4 mm**。
- **下颌角 / V-line**：外板或下颌角截骨收窄下脸。单侧外板约可收 **5–6 mm**；双侧下颌角间距文献均值约减 **12–14 mm**（一例 **123.7 → 110 mm**）。下颌角角度可从约 **112–115°** 增到约 **129–130°**。截骨线与下牙槽神经管保持至少 **3–5 mm**。常与缩颏、颧骨内推一起做。

演示滑块建议：下巴前突 +4/+6/+8 mm；颧宽 −3/−5/−7 mm；下颌角间距 −6/−10/−13 mm。

## 额与眉

- **眉提升（内镜/额眉提升）**：长期测量均值大约内侧 **3.3 mm**、中央 **3.9 mm**、外侧 **4.4 mm**。临床更希望内侧和中央只抬 **1–2 mm**，外侧 **4–5 mm**，眉尾 **6–7 mm**，避免「惊讶眉」。女性眉峰约在眶缘上 **1 cm**、位于外侧三分之一；男性眉多贴近眶缘、较平。切口常见 3–5 个，各长 **1–2 cm**。
- **发际线降低 / 额头缩短**：女性眉间到发际理想约 **5–6.5 cm**。单次可降低平均约 **2 cm**（头皮松时可到 **1.5–5 cm**）。每道帽状腱膜切开大约多推进 **1–2 mm**。若不同时松解眉，剥离停在眉上 **2–3 cm**，避免把眉一起抬高。
- **肉毒与填充辅助提眉**：诊所菜单常见，升幅小于手术。填充例：颞部与眉周小剂量（文献病例眉周数个 **0.1 mL** 点，颞部约 **0.4 mL**），外眦轴常被描述为约 **12–14°** 较开。演示可把非手术提眉设成外侧 **1–2 mm**，并标明依据弱于手术测量。

## MVP 先做哪几项

照片叠加最容易看出、参数也最干净的五项：

1. 双眼皮：褶皱高度 6/7/8 mm + 开扇或平行。
2. 开内眼角：睑裂约 +1～2 mm，内眦距约 −2.5 mm。
3. 隆鼻：鼻背 +2～4 mm，鼻尖略前突，鼻唇角收到约 95–100°。
4. 玻尿酸丰唇：合计约 1 mL，前突约 +1 mm。
5. 垫下巴：前突 +4/+6/+8 mm。

后续需求把第一版收成三项：双眼皮、隆鼻、丰唇，并把嘴角上扬挂在唇与口周。见 `医美术后效果演示MVP需求说明.md`。

第二批再加：嘴角上扬（注射约 +2°，手术约 +7°）、轻度上睑下垂（+1～2 mm）、外眼角（+3 mm）、泪沟（0.3 mL/侧）、颧骨宽（−5 mm）、下颌角（双侧合计约 −12 mm）、眉尾（+4～5 mm）。骨性项目在正脸照片上主要改宽度，隆鼻、垫下巴、丰唇主要改侧脸；嘴角上扬在正脸上就能看见。

## 使用时的边界

- 滑块用「轻度 / 常见 / 明显」三档，不要把文献极值当成默认术后图。
- 闭眼设计的双眼皮毫米数不等于睁眼可见宽度。
- 东亚隆鼻以加高和鼻尖支撑为主，鼻背降低不是默认项。
- 嘴角上扬的注射档和手术档不要用同一套角度。注射大约是几个百分点的高度或约 2°；手术文献均值接近把 −3° 收到 +3.5°。填充木偶纹不等于抬口角。
- 所有叠加图需标注为模拟，不能当成手术承诺或医疗建议。
