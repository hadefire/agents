# 医美术后效果演示

诊所内部使用的浏览器端 MVP。流程包括正侧脸采集、参数选择、局部几何模拟和术前/模拟对比。所有输出固定标注：

> 模拟效果，非医疗建议，不作为手术承诺

## 本地预览

```bash
npm install
npm run dev
```

打开 `http://localhost:5173`。演示账号为 `consultant`，访问码为 `clinic-demo`。登录后可以上传正侧脸照片，也可以点击“使用示例影像”直接体验完整流程。

## 验证

```bash
npm test
npm run build
```

当前模拟项目：

- 双眼皮：6 / 7 / 8 mm，开扇或平行
- 隆鼻：鼻背 +2 / +3.5 / +5 mm、鼻翼内收、鼻尖比例与鼻唇角
- 丰唇：0.8 / 1.0 / 1.2 mL，侧脸前突约 1 mm
- 嘴角上扬：注射固定约 +2°；手术约 +3° / +5° / +7°

照片在浏览器内存中处理，不上传服务器。MediaPipe 模型与 WASM 已放在 `public/`，断网环境也可运行。
